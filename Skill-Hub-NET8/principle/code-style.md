# Layer 1 Principle — Code Style

- 型別與類別使用 PascalCase，變數與函式使用 camelCase，全域常數使用 UPPER_SNAKE_CASE。
- 命名限用完整英文詞，除 id, url, api, dto, db 外禁止縮寫，且名稱須能自我解釋。
- 每個函式或方法僅限單一職責，長度不超過 30 行，超過必須重構拆分。
- 函式參數上限 4 個，超過改用物件傳入；禁用布林參數控制行為分支，改拆分為獨立函式。
- 程式碼嵌套深度上限 3 層，超過必須提早 return 結束分支或拆分子函式。
- 全面禁用魔術數字（0, 1, -1 除外），所有字串與數值設定值必須提取為命名常數。
- 嚴格禁止未使用的變數、匯入（import）、函式或被註解掉的程式碼殘留於 codebase。
- 僅在說明「函式或方法的用途（當名稱無法完整表達時）」、「複雜演算法邏輯」、「特定業務規則來源意圖」與「非直觀的架構決策原因」時撰寫備註。
- 嚴禁撰寫逐字複述程式碼行為的廢話備註；程式碼變更時必須同步更新或刪除關聯備註。
